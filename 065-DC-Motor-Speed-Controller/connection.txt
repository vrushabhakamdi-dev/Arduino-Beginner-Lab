CONNECTIONS

BOARD: Arduino Uno

L298N MOTOR DRIVER
ENA  → Arduino D5     PWM speed control (remove the ENA jumper cap)
IN1  → Arduino D6     motor direction (held HIGH)
IN2  → Arduino D7     motor direction (held LOW)
OUT1 → DC motor terminal A
OUT2 → DC motor terminal B
+12V → external 6-12V supply (+)
GND  → external supply (-) AND Arduino GND (common ground)
5V   → leave unconnected (on-board regulator feeds it)

DC MOTOR (6-12V)
terminal A → L298N OUT1
terminal B → L298N OUT2

10K POTENTIOMETER
left leg  → Arduino 5V
wiper     → Arduino A0     speed setpoint (0..1023)
right leg → Arduino GND

BREADBOARD / JUMPER WIRES / USB CABLE
no pin mapping - used for prototyping and power

L298N WIRING OVERVIEW

  ARDUINO UNO     L298N               MOTOR
  ----------     -----               -----
  D5  ---------> ENA
  D6  ---------> IN1
  D7  ---------> IN2
  GND --------> GND  <--- external supply (-)
                 +12V  <--- external supply (+)
                 OUT1 ---> motor terminal A
                 OUT2 ---> motor terminal B

NOTES
- Remove the ENA jumper cap, otherwise the L298N runs at full speed and
  the PWM on D5 does nothing.
- Power the motor from a SEPARATE 6-12V supply, never the Arduino 5V pin.
- The supply (-) must be tied to Arduino GND (common ground) or the
  driver will not respond to the logic pins.
- Direction is fixed in code: IN1 HIGH, IN2 LOW; only D5 PWM changes speed.
