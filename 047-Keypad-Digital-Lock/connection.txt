CONNECTIONS

BOARD: Arduino Uno

4x4 MEMBRANE KEYPAD
ROW1 → Arduino D9    keypad row 1 (keys 1 2 3 A)
ROW2 → Arduino D8    keypad row 2 (keys 4 5 6 B)  <-- SHARED with the buzzer
ROW3 → Arduino D7    keypad row 3 (keys 7 8 9 C)
ROW4 → Arduino D6    keypad row 4 (keys * 0 # D)
COL1 → Arduino D5    keypad column 1
COL2 → Arduino D4    keypad column 2
COL3 → Arduino D3    keypad column 3
COL4 → Arduino D2    keypad column 4

PIEZO BUZZER
+ → Arduino D8       tone() output - SAME pin as keypad ROW2
- → Arduino GND

LCD 1602 (I2C BACKPACK, address 0x27)
SDA → Arduino A4     I2C data
SCL → Arduino A5     I2C clock
VCC → Arduino 5V
GND → Arduino GND

NOTES
- D8 IS USED TWICE, exactly as the sketch is written: ROW_PINS = {9, 8, 7, 6}
  and BUZZER_PIN = 8. The buzzer (+) and keypad ROW2 really are on one wire.
- Why it still works: the beeps block with delay() and the keypad is not
  scanned while tone() runs, and when scanning, the row line only drives the
  buzzer silent. If the keys 4/5/6/B act up or you hear extra ticks, move the
  buzzer to a free pin (D10, D11, D12 or D13 are free) and change BUZZER_PIN
  in the sketch - nothing else needs to change.
- The keypad has no power pins, only the eight row/column wires. Match the
  printed ROW1..ROW4 / COL1..COL4 labels (some keypads say R1..R4 / C1..C4).
- The Keypad library enables the internal pull-ups itself, no resistors needed.
- A piezo buzzer is polarised: "+" to the pin, "-" to GND.
- Breadboard, jumper wires and the USB cable complete the build.
