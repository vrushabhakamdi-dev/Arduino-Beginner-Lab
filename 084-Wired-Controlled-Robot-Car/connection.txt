CONNECTIONS

BOARD: Arduino Uno

HAND CONTROLLER PUSH BUTTONS (tether cable, 5 conductors)
FORWARD button → Arduino D2     (other leg → GND)
BACKWARD button → Arduino D3    (other leg → GND)
LEFT button → Arduino D4        (other leg → GND)
RIGHT button → Arduino D5       (other leg → GND)
GND (shared return) → Arduino GND   (one wire serves all four buttons)

  All four buttons use INPUT_PULLUP, so no external resistors are needed.
  Tether = 4 signal wires + 1 ground wire running to the hand controller.

L298N MOTOR DRIVER
ENA → Arduino D11    (left motor speed, PWM - ENA moved off D5, remove ENA jumper cap)
IN1 → Arduino D6     (left motor direction)
IN2 → Arduino D7     (left motor direction)
IN3 → Arduino D8     (right motor direction)
IN4 → Arduino D9     (right motor direction)
ENB → Arduino D10    (right motor speed, PWM - remove the ENB jumper cap)
+12V → 6-12V battery pack (+)
GND → battery (-) AND Arduino GND (common ground)
OUT1/OUT2 → left DC motor
OUT3/OUT4 → right DC motor

  battery (+) → L298N +12V
  battery (-) → L298N GND → Arduino GND     (one joined ground)
  L298N OUT1/OUT2 → left motor
  L298N OUT3/OUT4 → right motor

NOTES
- PIN QUIRK: the buttons take D2-D5, so ENA is on D11 (a PWM pin), NOT the usual D5.
- Power the motors from the separate 6-12V pack, never from the Arduino 5V pin.
- Battery (-) must be joined to Arduino GND or the driver will not respond.
- Take the ENA and ENB jumper caps off, otherwise PWM speed control is ignored.
- If a wheel turns the wrong way, swap that motor's two wires - no code change.
- No signal wiring: robot chassis with caster wheel, breadboard, jumper wires, USB cable.
